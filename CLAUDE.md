# DU Web Platform — админ-панель (Astana IT University)

Прототип веб-платформы DU: авторизация + модуль «Журнал оценок».
Перенесён из чата claude.ai, где собирался по макетам Figma.
Стек: React 18 + Vite + Mantine UI 7 (переведено с ванильного HTML/CSS/JS).

## Запуск
`npm install`, затем `npm run dev` (Vite, по умолчанию порт 5177 — см. `.claude/launch.json`).
Демо-вход: кнопка «Войти в демо» или `admin` / `admin123`.

## Структура
- `index.html` — точка входа Vite, монтирует `#root`.
- `src/main.jsx` — `MantineProvider`, `Notifications`, `LangProvider`, `DataProvider`.
- `src/theme.js` — тема Mantine: радиусы, цвет `brand` (`#006fff`), кастомная палитра `dark.*`
  подогнана под тёмные токены Figma (`--mantine-color-text/dimmed/placeholder/default/body` и т.д.
  уже совпадают со светлой палитрой Mantine `gray.*` — так был сделан макет).
- `src/i18n.jsx` — тексты RU / KZ / EN (объект `T`) + `LangProvider`/`useI18n()`, язык в `localStorage`.
- `src/styles.css` — то, что не покрывается темой Mantine напрямую: фон под auth/app (`--bg-page`/`--bg-app`
  не имеют готового аналога в Mantine), переключение свет/тёмный логотип, активная вкладка сайдбара,
  адаптив `@media (max-width:860px)`.
- `src/components/` — `AuthScreen`, `Shell` (топбар + сайдбар + контент), `TopBar`, `Sidebar`,
  `PageHeader` (хлебные крошки + шапка: надзаголовок, заголовок, сведения `meta`, `actions`),
  `SettingsView` (таблица лет, `Pagination`, `Select`),
  `YearSettingsForm` (форма года: секции `SECTIONS`, `NumberInput`, сохранение + тост), `Logo`.
  `CopySettingsModal` (модалка «Копирование настроек», открывается из `SettingsView`).
  Копирование: цели — следующий год (`nextYear`) + все годы, кроме исходного; копирование на новый год
  добавляет его в таблицу.
- `src/data/` — бэкенда нет:
  - `demo.js` — демо-данные: годы, настройки годов (`SEED_SETTINGS` для 2026-2027 и 2025-2026), 12 журналов.
    Журнал `oop` («ООП», 2025-2026) собран вручную — по обучающемуся на каждый сценарий допуска
    (допуск, недопуск по РД / РК2 / посещаемости / нескольким причинам, нет РК2, нули, дроби, нет ИК,
    ручной РД). Остальные генерируются детерминированно (`mulberry32`). `web` — 36 дат (широкая таблица),
    `math` — оценок нет, `phys` — ошибка загрузки до первого показа (проверка «Повторить»).
  - `store.jsx` — `DataProvider`/`useData()`: `years`, `yearSettings`, `scores` (правки РК1/РК2/ИК/ручного РД
    поверх `initialScores`), всё в `localStorage` под ключом `du-data-v1`. `saveScores` асинхронный и бросает
    исключение, если не удалось записать, — модалка редактирования тогда остаётся открытой.
  - `dailyGrades.js` — `useDailyGrades(journal)`: демо-замена эндпоинта ежедневных оценок из Moodle
    (состояния `loading` / `success` / `empty` / `error`, `retry`, кэш на сессию).
- `src/journal/` — логика журнала:
  - `calc.js` — `parseScore` (пусто = нет оценки, 0 — оценка, `,` и `.`), `computeScores` (авто-РД = среднее
    выставленных ежедневных + РК1 + РК2, отсутствующие не считаются нулями; ИО = 60% РД + 40% ИК только при
    наличии обоих), `admission` (`ok` / `fail` / `unknown` + причины), `yearRules` — пороги и точность из
    настроек года журнала (точность = число знаков из настроек; без настроек — без округления).
  - `useJournal.js` — строки журнала с расчётами и допуском, форматирование, тексты причин, фильтр строк.
- `src/components/journal/` — раздел «Журнал»: `JournalModule` (навигация список → журнал → обучающийся,
  хранит фильтры, чтобы они сохранялись при возврате), `JournalList`, `JournalPage` (шапка из макета,
  вкладки «Обучающиеся»/«Потоки», фильтры поиск / группы / «Допуск к ИК»), `JournalTable`
  (обычная `<table>` — стили `.du-jt*` в `styles.css`: закреплены шапка и колонка «Обучающийся» с группой
  под ФИО; дальше посещаемость, лента «Оценка + дата» с РК 1/РК 2 по их датам (`timeline()`), блок итогов
  РК 1 · РК 2 · РД · ИК · ИО; значения ниже порога — `data-bad`, красные),
  `RdBadge` (РД: заливка ячейки по статусу + иконка + подсказка допуска; карандаш — ручной РД),
  `EditScoresModal` (черновик, проверка ввода, «Сохранить» недоступно при ошибках), `StreamsSummary`
  (вкладка «Потоки»: сводка допуска по группам), `StudentPage`, `DailyStatus`.
  Навигация — состояние, без роутера: кнопка «Назад» браузера не работает.
- Стили подписей полей (Figma Label: 14/20 SemiBold, описание 12/16, 4px до поля) — глобально
  в `theme.js` (`InputWrapper`) + одно правило в `styles.css`.
- `public/assets/` — логотип AITU (светлый/тёмный), конвертирован из брендбукового .ai.

Иконки — `lucide-react` (не `@tabler/icons-react`, чтобы сохранить правило «иконки — только Lucide»).
Тёмная/светлая тема — встроенный механизм Mantine (`useMantineColorScheme`/`useComputedColorScheme`,
persist в `localStorage` из коробки), не собственная реализация.
Тосты — `@mantine/notifications` вместо самодельного `.toast`.

## Дизайн-правила
- Шрифт Roboto: 24/32 Bold (h3), 20/24 Bold (h4), 14/20 Regular/SemiBold, 12/16.
- Цвета: primary `#006fff`, border `#dee2e6`, dimmed `#868e96`, placeholder `#adb5bd`,
  error `#fa5252`, фон приложения `#f8f9fa`, фон входа `#e9ecef`, primary-light `rgba(34,139,230,.1)`.
- Радиусы: 4 / 8 / 24 / 32. Отступы: 4 / 8 / 12 / 16 / 20 / 24.
- Иконки — только Lucide.
- Все строки интерфейса — через `T` в трёх языках (KZ / RU / EN).
- Макет сделан на Mantine UI — при переходе на React логично взять Mantine.

## Известные отличия от макета
- В макете «Всего записей: 120» и 10 страниц при 5 годах — сделано по реальным данным (6 записей:
  добавлен 2026-2027, текущий учебный год журналов).
- Аватар — инициалы вместо фото.
- Логотип из брендбука (.ai), в Figma вариант с надписью капсом.
- Разделитель в хлебных крошках — Lucide `Slash` (длиннее короткого слэша из Figma; правило «только Lucide»).
- Тексты формы года и модалки копирования на KZ / EN переведены вручную — в Figma только RU, нужна вычитка.
- Список целевых годов в модалке копирования в Figma не показан — выбран вариант «следующий год + остальные».
- Тёмная тема: у Mantine-вариантов `light`/`subtle` текст бледно-голубой (`brand.1`) — «Копировать»
  в таблице, «Отмена» в модалке. Макетов тёмной темы нет, не трогали.
- Радиус модалки 16px задан числом: в Figma `radius-lg` = 16, а в теме `lg` переопределён на 24 под карточку входа.
- Журнал: тексты KZ / EN и казахские сокращения (АБ 1, АБ 2, ЖР, ҚБ, ҚБа) и английские (MC 1, MC 2, AR, FE, FG)
  придуманы — нужна вычитка. Академический период в демо — «N семестр». Коды журналов, вид занятия,
  язык, онлайн, форма ИК, проктор, даты РК — демо-данные (`META` в `demo.js`).
